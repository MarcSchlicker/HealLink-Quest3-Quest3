# Projektkontext

Für Änderungen an Multiplayer, Bildschirmfreigabe oder Builds zuerst docs/AI_CONTEXT.md und die passende Zeile in docs/FEATURE_MAP.md lesen. Verhalten und Protokoll in docs/MULTIPLAYER.md sowie tatsächlich ausgeführte Tests in docs/TESTING.md gemeinsam mit dem Code pflegen. Keine erfolgreiche Geräteabnahme aus einem APK-Build ableiten. Generierte Unity-Verzeichnisse und APKs bleiben außerhalb von Git.
