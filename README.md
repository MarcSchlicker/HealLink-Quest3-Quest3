# HealLink Quest 3 ↔ Quest 3

Two Quest 3 headsets, connected over the same Wi-Fi.

The trainee shares their headset view, including passthrough. The expert sees that view and sends hand movements back. Both can talk over voice chat.

## Run it

1. Open the project in Unity **6000.6.7f1** with Android Build Support.
2. Build via **HealLink → Build Multiplayer APK** and install it on both headsets.
3. Start the app and choose **Trainee** on one headset and **Expert** on the other. Aim with the hand laser and pinch to select.
4. Allow microphone access and confirm screen sharing on the trainee.

The headsets find each other automatically. Press **B** to return to the menu.

Successor to [HealLink-HL2-Quest3](https://github.com/MarcSchlicker/HealLink-HL2-Quest3).
